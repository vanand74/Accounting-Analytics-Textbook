Introduction and Welcome#

Welcome to ACC 3323, Data Analytics for Accounting!

Data analytics is a process for using data to inform business decisions. In this course, you will learn this process and apply it to accounting tasks.

You can learn this process in any data-oriented software package like Excel, Tableau, Alteryx, or Power BI. However, such tools are not the best way to learn the process of data analytics. It is too easy to use these tools without understanding what you are doing. That leads to flawed analyses and poor work. Therefore, a better approach is needed to learn data analytics.

Many practicing data analysts and data scientists use a programming language like Python, R, or SQL. A quick search for “popular language for data analytics” reveals that Python, R, and SQL lead the industry. Why are these languages so popular in data analytics? Because working in a true programming language enforces best practices:

  • Explicit Logic: You must create a sequence of steps. This forces you to think through how you transform your data.

  • Auditability & Reproducibility: Your code is an audit trail. This allows you and others to verify, review, and reproduce your work.

  • Data Integrity: Your code and your data are separate (unlike in Excel). This protects your original data from accidental changes.

  • Efficiency: When new data arrives, you can just run your code again – no copying, pasting, or updating broken Excel formulas required.

Don’t misunderstand – Excel is a fantastic tool that I use regularly. However, once you master logic through code, transferring those skills to spreadsheet tools like Excel becomes second nature. You will find yourself working faster, smarter, and with far fewer errors.

I have chosen SQL as our primary learning tool in ACC 3323. We will begin by exploring how companies store data in databases. We will then learn to write SQL SELECT statements to extract and transform that data. As you will see, SQL provides an ideal framework for structuring your analytical thinking.

Don’t worry! My goal is not to turn you into a programmer or data scientist. My goal is to teach you some analytics concepts and skills that you will use as a practicing accountant. SQL is simply a tool for learning those concepts and skills.

As a bonus, SQL will give you lots of “street cred” when you interview for jobs. Accounting partners and recruiters are always impressed when students possess real SQL skills. Make sure to add SQL to your resume!
